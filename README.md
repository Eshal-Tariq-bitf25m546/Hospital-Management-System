# Hospital Management System

## 📌 About the Project

The **Hospital Management System** is a C++ project designed to simplify and organize basic hospital operations. It provides a structured way to manage hospital-related information through a user-friendly, menu-driven interface.

## ✨ Features

- Patient information management
- Doctor information management
- Appointment management
- Organized hospital records
- Menu-driven interface

## 🛠️ Technologies Used

- **Programming Language:** C++
- **IDE:** Visual Studio Code / Dev-C++

## 🚀 Getting Started

### Prerequisites

- A C++ compiler (such as GCC or MinGW)
- A code editor or IDE

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Compile the C++ source file:

   ```bash
   g++ main.cpp -o HospitalManagement
   ```

4. Run the program:

   ```bash
   ./HospitalManagement
   ```

   On Windows PowerShell:

   ```powershell
   .\HospitalManagement.exe
   ```
